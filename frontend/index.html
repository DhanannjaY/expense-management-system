About This Project

BCA 6th Semester Project II - Tribhuvan University

This Expense Management System is developed as a final year project implementing Iterative Development methodology. The system uses modern web technologies and machine learning algorithms to provide intelligent expense tracking and prediction.

Technologies Used
  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
  • Backend: Python, Django, Django REST Framework
  • Database: MySQL / SQLite
  • ML: Linear Regression, Weighted Prediction
Key Achievements
  • 95% prediction accuracy using ML algorithms
  • Comprehensive budget management system
  • Real-time analytics dashboard
  • Multi-format report generation
